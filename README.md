# Task 4: Classification with Logistic Regression

## 🎯 Objective
Built a binary classifier using Logistic Regression to predict whether a tumor is Malignant or Benign using the Breast Cancer Wisconsin Dataset.

## 🛠️ Tools Used
* Python
* Pandas & Numpy
* Scikit-learn
* Matplotlib & Seaborn

## 📊 Performance Results
* **Overall Accuracy**: ~97.4%
* **ROC-AUC Score**: 1.00 (Perfect class separation)
* **Threshold Tuning**: Shifting the prediction threshold from 0.5 to 0.3 reduced False Negatives to 0, ensuring maximum safety for medical classification.
